# Life OS Android

Native Android MVP, Guest-only, offline-first.

## Included
- Guest mode (no Gmail/password)
- Tasks stored locally
- Android notifications
- Exact alarm support on supported Android versions
- Dark Life OS UI
- Minimum Android 7.0 (API 24)
- Target SDK 35

## Build
Open the project in Android Studio and build an APK/AAB.

For Google Play, use an Android App Bundle (.aab), create a release signing key, and upload through Google Play Console.

## Important
The current MVP deliberately does not implement Google login or cloud sync.
It does not collect account credentials.
